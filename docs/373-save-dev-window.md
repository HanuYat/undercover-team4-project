# 세이브 편집기 사용법

- **대상:** 특정 라운드·자금·구매 상태에서 게임을 시작해 보고 싶은 팀원
- **범위:** A장 사용 순서 · B장 각 칸이 바꾸는 것 · C장 함정 모음
- **코드:** [SaveDevWindow.cs](../Assets/Scripts/Editor/SaveDevWindow.cs) (`Editor` 폴더 — 빌드에 안 들어간다) · 저장 본체는 [SaveService.cs](../Assets/Scripts/Save/SaveService.cs)
- **최초 작성:** #373 (세션 세이브/로드)

> **한 줄 요약.** 5라운드 밸런스를 보려고 5라운드까지 실제로 플레이할 필요가 없다.
> 원하는 판 상태를 창에 적어 올리고, '이어하기'로 거기서부터 시작한다.

---

# A장 — 사용 순서

## A-1. 전제

이 게임의 세이브는 **로컬 파일이 아니라 UGS Cloud Save의 키 하나**이고, 저장소가 로그인 계정 단위다.
그래서 **플레이 모드에서 로그인이 끝난 뒤에만** 읽고 쓸 수 있다.

세이브는 **지금 로그인한 계정의 것**이다 — 방을 만들 인스턴스(보통 메인 에디터)에서 만들 것.

## A-2. 창 열기

```
Tools/세이브 편집기
```

Play 중이 아니어도 값 편집은 되지만, 올리고 내리는 버튼은 잠겨 있다.

## A-3. 순서

### ① Title Scene에서 Play

콘솔에 `[AuthBootstrap] 익명 로그인 완료 / playerId: xxx`가 뜨면 준비 끝이다.
창 위쪽 안내가 노란 `로그인 대기 중`에서 회색 `로그인됨 / PlayerId: ...`로 바뀌고 버튼이 켜진다.

### ② 값 채우기

각 칸이 무엇을 바꾸는지는 B장 표 참고. 지갑은 `내 PlayerId 추가` 버튼으로 넣고 금액만 적는다.

### ③ 올리기

`이 값으로 덮어쓰기` → 콘솔에 `[세이브] 저장 완료 — 3라운드, 팀 자금 5000, 지갑 1명`.
값을 고쳐 몇 번이든 다시 눌러도 된다.

### ④ Play를 껐다 켠다

세이브 유무 조회는 **로그인 직후 한 번만** 돌기 때문에, 올린 그 자리에서는 '이어하기'가 켜지지 않는다.

다시 Play하면 `[세이브] 불러옴 — 3라운드, 팀 자금 5000, 지갑 1명`이 찍히고 타이틀의 **이어하기**가 켜진다.
누르면 세션이 만들어지면서 상주 홀더들이 그 값으로 스폰된다 — `[상점] 세이브 복원 — 소지형 N개, 설치형 M종`.

## A-4. 나머지 버튼 3개

| 버튼 | 쓰임 |
|---|---|
| 클라우드에서 불러오기 | 지금 저장된 세이브를 창에 역으로 채운다. 실제 플레이로 만들어진 값을 확인하거나, 한 칸만 고쳐 다시 올릴 때 |
| 지금 판 상태로 저장 | 실제 저장 경로(`SaveService.SaveAsync`). 플레이 도중 아무 지점에서 눌러 그 상태를 굳혀 두고 반복 재현한다. 호스트에서만 의미가 있다 |
| 세이브 지우기 | '이어하기'가 없는 상태(= 새 판만 가능)를 테스트할 때 |

# B장 — 각 칸이 바꾸는 것

| 칸 | 복원되는 곳 | 효과 |
|---|---|---|
| 라운드 | `RoundProgress.Current` | 그 라운드부터 시작 = **난이도(할당량)가 그 수준**으로 잡힌다 |
| 팀 자금 | `TeamFund.Balance` | 상점 소지금 |
| 맵 인덱스 | `MapSelection.SelectedIndex` | 다음 출동 맵. 범위를 벗어나면 조용히 0번으로 떨어진다 |
| 구매한 소지형 | `ShopPurchases.Carried` | 게임 씬 진입 시 `ShopDelivery`가 본부 택배 지점에 다시 배달한다. 같은 프리팹을 두 번 넣으면 두 개 |
| 구매한 설치형 | `ShopPurchases.Installables` | 본부의 해당 설비가 켜진 채로 시작 |
| 개인 지갑 | `PlayerWallet` | 스폰 시 1회 복원. **PlayerId 기준** |

소지형은 '추가' 칸에 프리팹을 끌어다 놓으면 목록에 쌓인다(칸 자신은 계속 비어 있다).
세이브에 적히는 id가 프리팹 이름이라([SaveItemLookup.cs](../Assets/Scripts/Save/SaveItemLookup.cs)) 이름을 손으로 적을 일은 없다.

# C장 — 함정 모음

## C-1. 지갑이 0원으로 시작한다

`PlayerId`가 한 글자라도 어긋나면 **에러 없이** "이번 판에 새로 합류한 사람"으로 처리돼 0에서 시작한다.
`내 PlayerId 추가` 버튼을 쓸 것. 손으로 적지 말 것.

MPPM 클론은 계정이 달라 PlayerId도 다르다 — 클론 지갑까지 테스트하려면 클론 콘솔의 playerId를 보고 엔트리를 하나 더 추가한다.

## C-2. 소지형이 복원되지 않는다

복원은 `DefaultNetworkPrefabs.asset`에 등록된 프리팹만 된다(등록 명부를 이름으로 훑는 방식).
미등록 프리팹은 올라가기는 하고, 나중에 `[상점] 세이브의 소지형 'X'을(를) 찾지 못해 건너뛴다` 경고와 함께 사라진다.

프리팹 **파일 이름을 바꾸면** 그 아이템에 한해 기존 세이브가 복원되지 않는 것도 같은 이유다.

## C-3. 만들어 둔 세이브가 사라졌다

둘 중 하나다.

- **덮였다** — 실제 저장이 씬을 넘는 두 길목(상점 출동 / 라운드 성공 종료)에서 각각 1회 돈다. 같은 조건을 또 보려면 다시 올린다.
- **지워졌다** — 라운드 **실패**로 판이 끝나면 세이브를 삭제한다(이어할 판이 없다는 뜻이므로). 실패 흐름을 테스트했다면 다시 만들어야 한다.

## C-4. 포맷 버전

`SessionSaveData.k_version`이 올라가면 그 이전에 올려 둔 세이브는 읽지 않고 버린다(`[세이브] 포맷 버전이 달라 무시한다`).
필드가 추가된 뒤에는 테스트 세이브를 다시 만들 것.
