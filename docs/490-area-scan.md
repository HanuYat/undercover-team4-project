# #490 구역 스캔 — 구현 현황 · 테스트 항목 · 보류된 사운드 배선

## Context

반경 안에 진범이 있는지만 알려 주는 소지형 아이템. **이슈 원안에서 두 축이 바뀐 채로 구현됐다**(2026-08-23 결정):

| 항목 | 이슈 원안 | 구현된 것 |
|---|---|---|
| 결과 표현 | 사이렌 소리 / 무음 | **초록 / 빨강 링** (+ 판독음). 무음 분기 없음 |
| 사용 제약 | 일회용 소모 (`ServerConsume`) | **쿨타임 60초, 소모되지 않음** |

이 변경으로 이슈의 미결 항목 중 **7번(매 라운드 재배달) · 8번(가격) · 9번(미사용 회수)이 사라졌다** — 소모되지 않으므로 재배달이 곧 정상 동작이다. **4번("없음"과 "실패"의 구분)도 사라졌다** — 빨강 링 자체가 "정상 동작했고 없었다"는 신호라 조용한 실패와 구분된다.

확정된 나머지 결정: 링은 **근처 플레이어 전원**이 본다 / 진범 기준은 **`IsCriminal`만** / **즉발**(채널링 없음) / **먹통 중 사용 차단**.

## 구현 범위

| 구성요소 | 경로 | 역할 |
|---|---|---|
| 아이템 본체 | `Assets/Scripts/Item/AreaScanner.cs` | 즉발 사용, 반경 판정(서버), 쿨타임, 결과 전파 |
| 링 연출 | `Assets/Scripts/Vfx/AreaScanRingView.cs` | `LineRenderer` 원을 0→반경으로 확장 후 페이드. 순수 로컬 |
| 오너 토스트 | `Assets/Scripts/UI/AreaScanPresenter.cs` | 쿨다운·먹통 사유를 `App.UI.Toast`로 |
| 먹통 게이트 | `Assets/Scripts/Item/DeviceBlackoutGate.cs` | 개인 스캐너와 공용(신규 추출, `Scanner` −12줄) |

**설계상 짚어둘 두 가지**

- **반경 수집에 `Physics.OverlapSphere`를 쓴다.** `NpcSpawner.SpawnedNpcs` 순회가 더 싸지만, `m_spawnedNpcs.Add`는 [NpcSpawner.cs:298](../Assets/Scripts/NPC/NpcSpawner.cs:298) 최초 스폰 1회뿐이라 라운드 중 스폰되는 난동꾼·침입자·탈옥 NPC가 목록에 없다. 그들도 `CriminalAssigner.AssignLateSpawned`로 진범이 될 수 있어, 목록을 훑으면 **진범을 조용히 놓친다.** 대신 `Ragdoll` 레이어 제외 + 512칸 버퍼 + 포화 경고가 필요하다(1인당 뼈 콜라이더가 여럿이라 20m면 256칸도 찬다).
- **링은 `FxManager` 조합표만으로 못 낸다.** `PlayEverywhere`는 `position`/`normal`만 받아 반경·색을 실을 수 없다. 반경을 프리팹에 구우면 `m_scanRadius`와 조용히 어긋나므로, **소리만 `EFx`로 내고 링은 전용 로컬 뷰**로 갈랐다.

**쿨다운은 `Taser`(서버 로컬 float)가 아니라 `JailSirenButton`(종료 시각 `NetworkVariable<double>`) 방식이다.** 테이저 5초는 원형 게이지가 잠깐 돌고 끝나지만 60초 게이지는 화면을 계속 점유하고, 오너가 남은 시간을 알아야 장착 아이콘 힌트(`CanUse`)가 맞는다.

## 보류된 사운드 배선

**적용하지 않았다.** 아래는 지정만 해 둔 값이며, 클립을 붙일 때 그대로 쓰면 된다.

`Assets/Scripts/Data/AudioLibrary.asset`의 `m_entries`에 슬롯은 이미 잡혀 있고 `Clip`만 비어 있다:

| Id | enum | 붙일 클립 | Volume | MinDistance | MaxDistance |
|---|---|---|---|---|---|
| 28 | `EAudioClip.AreaScanHit` | `Assets/Imported/Audio/Jail_Siren.mp3`<br>`guid: 0fd98dfdb5464f1c9fc3657a05bf28a8` | 0.7 | 6 | 25 |
| 29 | `EAudioClip.AreaScanMiss` | `Assets/Imported/Audio/Ui_Fail.mp3`<br>`guid: 86fbb8a825129ef4ba8c5bceb3e4fd8b` | 0.45 | 3 | 25 |

- **Hit에 사이렌을 고른 이유** — 이슈 원안이 "반경 안에 진범이 있으면 사이렌"이었다. 임시 클립이지만 의도한 연출 방향과 어긋나지 않는다.
- **Miss는 짧고 밋밋한 신호음** — 두 소리가 확연히 달라야 색을 못 봐도 판정이 구분된다.
- **감쇠 25m**는 스캔 반경 20m보다 살짝 넉넉하게 잡은 값이다 — 링 안 전원이 듣고 조금 벗어난 사람까지 들린다. 판독음은 `FxManager.PlayHere` → `PlaySfxAt`로 **3D 재생**이라 이 값이 실제로 작동한다.
- 기존 `JailSiren`·`UiFail`과 같은 클립 에셋을 공유하게 되는데, 라이브러리가 Id→클립 매핑이라 정상적인 사용이다.

**미배선 상태의 동작**: `SoundManager.WarnOnce`가 `"[SoundManager] AreaScanHit 항목에 클립이 배정되지 않았다 — 해당 소리를 건너뛴다"`를 **1회만** 남기고 조용히 넘어간다. 도배되지 않으므로 이 상태로 테스트해도 무방하다.

씬 쪽 `FxManager` 조합표(`EFx.AreaScanHit`=9 → `Sound` 28, `AreaScanMiss`=10 → 29)는 `Map_Cyberpunk` · `Map_Apocalypse` · `Tutorial` **세 곳 모두 이미 배선돼 있다.** 클립만 채우면 바로 소리가 난다.
